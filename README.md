# Smart City Portal

A comprehensive civic issue reporting and management platform that connects citizens with local authorities for efficient urban problem resolution.

## 🌟 Features

- **User Registration & Login** - Secure authentication system
- **Report Civic Issues** - Submit reports for roads, streetlights, garbage, drainage, water supply, and more
- **Track Report Status** - Monitor your reports through pending, in-progress, and resolved stages
- **Admin Dashboard** - Comprehensive admin panel with analytics
- **Feedback System** - Submit feedback to improve services
- **Responsive Design** - Works on desktop and mobile devices

## 🚀 Live Demo

**[https://smartcity.gt.tc](https://smartcity.gt.tc)**

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript, Bootstrap 5
- **Backend**: PHP 8+
- **Database**: MySQL
- **Icons**: Font Awesome 6

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/YOUR_USERNAME/smart-city-portal.git
```

2. Import database:
- Create a database named `smart_city`
- Import `database.sql` file

3. Configure database connection:
- Edit `config.php` with your database credentials

4. Start your local server (XAMPP/WAMP)

5. Visit `http://localhost/smart-city-portal`
